# 🃏 Memory Match (神経衰弱) - Apps Hub

ブラウザ上で今すぐ遊べる、本格トランプデザインのシングルファイル神経衰弱（Memory Match）ゲームです。  
1人タイムアタック・記憶力AI対戦・2人パス＆プレイに対応し、12枚のサクッとプレイから52枚のフルデッキまで柔軟に難易度を選択できます。

> **🌐 Live Demo:**  
> ブラウザで今すぐ遊べる公開版はこちら 👉 **[https://selfup.net/memory/](https://selfup.net/memory/)**

---

## 🌟 主な機能 (Features)

### 1. 3つのゲームモード
- **1人タイムアタック (Solo):** 手数（ミス数）とタイムを計測し、最小手数クリアを目指す脳トレモード（難易度別ベスト記録を自動保存）
- **vs 記憶力AI対戦 (CPU):** 3段階の記憶難易度を選択可能なCPU対戦
  - `初級`: うろ覚え（記憶率 35%）
  - `中級`: 直近記憶（記憶率 75%）
  - `上級`: 完全記憶（一度開いたカードは100%忘れない）
- **2人パス＆プレイ (2P 対戦):** 1台のスマートフォンやPCを交互に操作して獲得ペア数を競うオフライン対戦

### 2. 4段階の枚数切り替え
- **12枚 (6ペア):** 隙間時間のサクッとプレイに最適
- **24枚 (12ペア):** 一般的な標準難易度
- **36枚 (18ペア):** 6×6グリッドの心地よい中上級バランス
- **52枚 (26ペア):** 本格的なフルデッキチャレンジ

### 3. 本格トランプ＆Apps Hubオリジナルデザイン
- クラシックカジノ風のダイヤモンド格子裏面に、Apps Hubのシンボルキューブ（`fa-cube`）メダリオンを刻印。
- 表面は世界基準のポーカーサイズトランプに倣い、対角コーナーインデックス（Playfair Display）と上下対称の整然たるピップ配置を実現。

### 4. 完全クライアントサイド動作 & Web Audio API
- 外部音声ファイルの読み込みゼロ。Web Audio API によるリアルタイム周波数合成でカードフリップ音、ペア成立チャイム、ミス音、勝利ファンファーレを生成。
- 外部サーバーへの通信は一切なく、スコアやお気に入り設定はすべて端末内（localStorage）に安全に保持されます。
